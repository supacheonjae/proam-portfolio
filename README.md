# 모두의프로암 V2 · Mobile engineering case study

Flutter 기반 모바일 앱 리뉴얼과 후속 운영 경험을 정리한 포트폴리오입니다.

공개 주소: https://supacheonjae.github.io/proam-portfolio/

## 구성

- `index.html`: 경력 요약, 담당 범위, 기술 사례, 출시·운영 설명
- `style.css`: 반응형 레이아웃, 모바일·인쇄·모션 감소 설정
- `script.js`: 실제 앱 캡처 목록, 시연 재생·일시정지, 섹션 탐색
- `assets/`: 공개용 앱 캡처 및 시연 파일

외부 라이브러리나 빌드 과정 없이 정적 파일로 동작합니다. 개인정보 수집, 분석 스크립트, 외부 폰트 요청을 사용하지 않습니다.

## 수정 기준

회사명·기간·역할·성과의 사실관계는 사람인 원본 이력서와 함께 관리합니다. 웹에는 실제 화면과 기술적 선택의 근거를 추가합니다. 이력서와 웹 사이의 자동 동기화는 없습니다.

문구 수정은 `index.html`, 시연 파일 및 캡션 수정은 `script.js`의 `demonstrations` 배열에서 합니다. 캡처 교체 시 파일명과 설명을 함께 확인합니다.

핵심 리뉴얼 기간과 이후 운영 개선을 구분합니다. 검증되지 않은 성능 개선 수치나 서비스 지표를 추가하지 않습니다.

## 로컬 확인

저장소 폴더에서 아래 명령을 실행하고 `http://localhost:8000`을 엽니다.

```sh
python3 -m http.server 8000
```

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)`를 사용합니다. 이후 `main`에 변경 내용을 올리면 자동 배포됩니다.

## 공개 범위

이 저장소에는 포트폴리오 페이지와 공개용 미디어만 포함됩니다. 서비스 앱 소스 코드, API 주소, 인증 정보는 포함하지 않습니다. 앱 상표·화면·콘텐츠의 권리는 해당 권리자에게 있습니다.

## 시연 미디어

첫 화면은 iOS Prod 캡처, 세 개의 시연 영상은 Android Prod 2.1.11(140)에서 촬영했습니다. 비로그인 조회 흐름으로 홈 탐색, 이벤트 상세, 공식 계정 피드의 이미지 보기를 보여줍니다. 시스템 상태 표시줄을 제외하고 웹 재생용으로 압축했습니다. 녹화 원본과 회사 앱 코드는 포함하지 않습니다.
